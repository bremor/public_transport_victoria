# Public Transport Victoria

Shows the next five departure times for a chosen Public Transport Victoria stop, line and direction as Home Assistant sensors, with the raw PTV departure data available in each sensor's attributes.

## Requirements

- An existing PTV **Dev ID** and **API key**, issued through the [PTV Timetable API](https://www.vic.gov.au/public-transport-timetable-api).
- Home Assistant with the integration installed and restarted.

> **Note:** PTV developer key registrations have been slow or stalled at times — see [issue #38](https://github.com/bremor/public_transport_victoria/issues/38). Existing Dev ID / API key credentials continue to work. New registrations may take an extended period before being approved.
